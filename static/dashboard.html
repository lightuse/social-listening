📖 使い方ガイド

🚀 基本的な使い方

  • リアルタイム監視: 画面上部の統計情報で現在の感情分析状況を確認
  • キーワード分析: 「キーワード」欄に調べたい単語を入力（例: AI, 人工知能）
  • フィルタリング: プラットフォーム（Twitter/YouTube/Reddit）や感情で絞り込み
  • データ検索: 🔍ボタンで既存データから即座に検索（高速）
  • 新規分析: 🚀ボタンで最新データを収集・分析（数分）
  • トレンドトピック: 話題になっているキーワードをクリックして詳細を確認

🔍 ボタンの違いについて

💡 2つのボタンの使い分け:
  • 🔍 データ検索: 既存のデータベースから条件に合致する投稿を即座に検索・表示（数秒で完了）
  • 🚀 新規分析開始: 選択されたプラットフォームから最新のデータをリアルタイムで収集し、AI分析を実行（2-5分程度）

🎯 使い分けのコツ:
  • 既存データの確認 → 🔍 データ検索
  • 最新の投稿を調べたい → 🚀 新規分析開始
  • Twitter APIを節約したい → プラットフォームでTwitter以外を選択

🛡️ プラットフォーム選択とAPI制限について

⚠️ 重要: Twitter API制限について
  • Twitter API: 使用量制限があり、過度な使用でレート制限が発生します
  • YouTube API: 比較的制限が緩く、安定して利用可能
  • Reddit API: 認証情報があれば制限が緩い

🎯 推奨使用方法:
  • Twitterのみの分析が必要でない場合は、プラットフォーム選択でYouTubeやRedditを選択
  • 新規分析は必要最小限に留め、まずはデータ検索で既存データを確認
  • Twitter分析は重要なキーワードやブランド監視時のみ使用

🔍 効果的なキーワード設定

💡 コツ:
  • 複数のキーワードはカンマで区切る（例: AI技術, ChatGPT, 生成AI）
  • 具体的な単語を使う（「AI」より「ChatGPT」の方が精度が高い）
  • ブランド名、商品名、サービス名を正確に入力

📊 データの見方

  • 感情分析:
    • 🟢 ポジティブ: 好意的・肯定的な反応
    • 🔴 ネガティブ: 批判的・否定的な反応
    • 🟡 ニュートラル: 中立的・事実的な言及
  • トレンドスコア: 数値が高いほど話題性が高い
  • 活動レベル: 🔴 活発 / 🟡 普通 / 🔵 低調

⚡ 便利な機能

  • 自動更新: ダッシュボードは30秒ごとに自動更新
  • トレンド期間変更: 過去24時間〜30日間から選択可能
  • 詳細レポート: 包括的レポートページで詳細分析
  • API利用: API仕様書でプログラマティックアクセス

🛠️ よくある問題と解決方法

⚠️ トラブルシューティング:
  • データが表示されない: ページを再読み込みするか、キーワードを変更してみてください
  • 分析が遅い: キーワード数を減らす（5個以下推奨）
  • エラーが出る: 一度ページを再読み込みしてください

📈 実践例

ブランド監視の例:
キーワード: あなたの会社名, 商品名
→ ネガティブが30%を超えたら要注意
競合分析の例:
キーワード: 競合他社名, 業界キーワード
→ トレンドトピックで業界動向をチェック
