🚀 基本的な使い方

Q1. アプリの使い方を教えてください

+

基本的な流れ:

  1. ブラウザで http://localhost:8002 にアクセス
  2. ダッシュボードで現在の状況を確認
  3. 「キーワード」欄に興味のある単語を入力
  4. 「分析開始」ボタンをクリック
  5. 15-20分後に結果を確認
💡 ヒント: 右下の「❓」ボタンをクリックすると詳細なヘルプが表示されます。

Q2. どんなキーワードを入力すればよいですか？

+

効果的なキーワード例:

✅ 良い例：
• ChatGPT, 生成AI, AI技術
• iPhone15, Apple, 新型iPhone
• あなたの会社名, 商品名

❌ 避けるべき例：
• AI（短すぎて関係ない投稿も拾う）
• 日本（範囲が広すぎる）
💡 コツ: 複数のキーワードはカンマで区切って入力してください（例: AI技術, 機械学習, ChatGPT）

Q3. トレンドトピックの見方を教えてください

+

トレンドトピックの指標:

  • トレンドスコア: 数値が高いほど話題性が高い
  • 活動レベル:
    • 🔴 活発 = 過去24時間で多くの投稿
    • 🟡 普通 = 適度な投稿量
    • 🔵 低調 = 投稿が少ない
  • 感情チップ: 😊ポジティブ / 😞ネガティブ / 😐ニュートラル

トピックをクリックすると詳細な分析結果が表示されます。

🛠️ トラブルシューティング

Q4. データが表示されません

+

解決方法を順番に試してください:

  1. ページの再読み込み: F5キーまたはブラウザの更新ボタン
  2. サンプルデータの確認: 初期状態ではサンプルデータが表示されるはずです
  3. キーワードの変更: より一般的なキーワードに変更してみてください
  4. 時間をおいて再試行: サーバーが処理中の可能性があります
# コマンドラインでサンプルデータを追加 python add_sample_data.py

Q5. 分析が遅い・止まってしまいます

+

パフォーマンス改善方法:

  • キーワード数を減らす: 5個以下に制限
  • 期間を短くする: 過去7日以内に設定
  • プラットフォームを限定: TwitterのみなどToに絞る
  • 時間をずらす: 混雑時間を避ける
⚠️ 注意: 大量のデータを処理する場合、15-20分程度かかることがあります。

Q6. エラーメッセージが表示されます

+

よくあるエラーと対処法:

  • 「データの読み込みに失敗しました」 → ページを再読み込み
  • 「APIエラー」 → 少し時間をおいて再試行
  • 「分析の開始に失敗」 → キーワードを確認して再入力
# システム状態の確認 curl http://localhost:8002/health

エラーが続く場合は、Dockerコンテナを再起動してください。

📊 データの解釈

Q7. 感情分析の結果はどう読めばよいですか？

+

感情分析の種類:

  • 🟢 ポジティブ: 好意的、肯定的、賞賛的な投稿
  • 🔴 ネガティブ: 批判的、否定的、不満を表す投稿
  • 🟡 ニュートラル: 中立的、事実的、感情的でない投稿
💡 解釈のコツ:
  • ネガティブが30%を超えたら注意が必要
  • ポジティブが70%を超えたら好評
  • 数値だけでなく、実際の投稿内容も確認する

Q8. どのプラットフォームのデータが信頼できますか？

+

プラットフォーム別の特徴:

  • Twitter:
    • ✅ リアルタイム性が高い
    • ✅ 即座の反応を把握
    • ⚠️ 短いメッセージで文脈が不明な場合がある
  • YouTube:
    • ✅ 詳細なコメント
    • ✅ エンターテイメント関連に強い
    • ⚠️ 更新頻度が低い
  • Reddit:
    • ✅ 深い議論と分析
    • ✅ 技術的な話題に強い
    • ⚠️ 特定のコミュニティに偏る場合がある
🚀 高度な使い方

Q9. APIを直接使って自動化したいです

+

API利用の基本:

# 感情分析結果の取得 curl "http://localhost:8002/api/v1/sentiment/summary?days=7" # トレンドトピックの取得 curl "http://localhost:8002/api/v1/trending-topics?limit=10" # 分析の開始 curl -X POST "http://localhost:8002/api/v1/analyze" \ -H "Content-Type: application/json" \ -d '{"keywords": ["AI技術"], "platforms": ["twitter"]}'

詳細は API仕様書 をご確認ください。

Q10. 定期的な監視を自動化したいです

+

自動化の例:

# cronで毎日12時に分析実行 # crontab -e で追加 0 12 * * * curl -X POST "http://localhost:8002/api/v1/analyze" \ -H "Content-Type: application/json" \ -d '{"keywords": ["あなたのブランド名"]}'

Python スクリプトでより高度な自動化も可能です。

🔗 その他

Q11. このシステムの制限事項はありますか？

+

現在の制限事項:

  • 同時に処理できるキーワードは10個まで推奨
  • 分析には15-20分程度の時間が必要
  • 過去のデータは最大30日間まで
  • リアルタイム更新は30秒間隔
⚠️ 注意: 大量のリクエストを送信するとAPIレート制限に引っかかる可能性があります。
